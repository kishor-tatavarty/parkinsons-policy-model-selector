PARKINSON'S POLICY REQUEST EVALUATION — CONSOLIDATED RESULTS
29 October 2026

SCOPE
120 Claude-generated requests,20 in each of six predefined language families,
60 per speech profile. Tested against a frozen narrow rule parser and an LLM
single-response interpretation path with a shared deterministic selector.
The structured arm receives reference fields. The two LLM arms share one saved
response per request. No classifier execution. These are not independent human
requests, a user study, or a new predictive-model test.

INTERPRETATION
The LLM enabled useful interpretation on language outside this frozen parser's
finite grammar. This supports its use for this defined language-interface scope.
It does not establish an advantage over every deterministic parser or correct
structured input. The parser's zero policy matches reflect strict field matching
and refusal of all120 requests, including supported partial-field omissions.
Validation cut the number of flagged wrong authorizations from8 to4, with lower
coverage and lower final-outcome agreement. It is a partial safeguard, not a
semantic correctness guarantee. Raw and validated semantic scores are identical
because they use the same generated interpretation. Validation does not rewrite it.

FAILURE LOCATIONS
Interpretation: priority confusion, negation, strictness, threshold rounding,
unnecessary clarification, unsupported metric/unit interpretation, omitted
clarification flags, and conditional-model scope errors.20 semantic mismatches
remain under the adjudicated rubric. Some match the expected model anyway.
Validation:23 outputs blocked, including correctly interpreted requests whose
quotes/numbers or unconditional-choice wording failed narrow checks. See
validation_blocks.csv for case-level categories and semantic correctness.
The generated cost request '5 cents' was incorrectly mapped to a false-positive
constraint. 'Above0.62' became inclusive and changed priority; both arms authorized
selection. A balanced-accuracy minimum was promoted to the ranking objective.

UNCERTAINTY AND GENERALIZATION
CSV includes descriptive95% Wilson intervals. Semantic LLM interval75.65–88.94%;
raw final-outcome interval86.36–96.00%;validated67.45–82.61%.
These assume independent requests; the deliberately constructed model-generated
set is not a probability sample of researcher language. The frozen set tests
six scoped families. It does not establish clinical robustness, general safety
or researcher usability. No multiplicity-adjusted population superiority claim.
Semantics are normalized field agreement with accepted alternatives; free-text
clarification quality is not certified by the automatic scorer. For example,
some conditional-choice clarification questions fail to explain the implementation
boundary clearly. Preserve that limitation when describing request understanding.
